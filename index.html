Explain It Section

  1. In your own words, how does your app change a sound wave into binary? Name the three steps. Sample the wave's height at equal time steps, round each height to the nearest level, then write each level in binary.
  2. Run Test A again with 2 bits, then 6 bits. Which gives more detail about the wave, and why? 6 bits gives more detail because it provides 64 levels instead of 4, allowing the binary representation to follow the wave's height much more closely, though it uses more bits.
  3. Which test has the longest wavelength? How is wavelength connected to frequency? Test B (200 Hz) has the longest wavelength. Wavelength is inversely connected to frequency; a higher frequency means a shorter wavelength.
  4. What was the hardest stage to build, and how did you fix it? Managing correct rounding of halfway sample heights and ensuring precise leading zeros for binary strings was challenging, which was resolved by implementing strict rounding functions and zero-padding logic.
